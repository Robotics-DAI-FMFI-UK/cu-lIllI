Different experiments are provided, each of them containing a .ttt file that represents a scene which must be loaded in CoppeliaSim, along with a folder containing the results.

The results are structured as follows:

    Each run produces two output files: one ending with 1.lua, and the other with 2.lua.

    Each file has a unique ID.

    The first file contains the best fitness value for each generation, with each row representing a new generation.

    The second file includes more structured information: it contains the gene of the best-performing individual and its fitness for every generation. In some cases, it also includes the fitness of each individual.
